## Implementation scope

Own Python child holds a stable file byte-range OS lock (Windows verified; POSIX branch unverified) and atomically writes only the exact private task journal under that lease. Node uses a private UTF-8 pipe for bounded requests, fixed receipts and lifetime ownership. Losing the holder rejects outstanding writes, denies later browser dispatches and closes/pauses the runtime. Journal writing in the holder prevents an old Node process from committing data after its physical owner has died. A normal release never unlinks the stable lock resource. Legacy JSON, empty or malformed markers are never rewritten based on age/PID. A crash before initial lock-header creation can remain an unconfirmed marker; no claim of universal recovery.
