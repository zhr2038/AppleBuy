目录：`E:\Apple Store\web\checkout-connector`。不要把旧 `web/chrome-connector` 公共只读探针当成这个购买执行器。

本人明确同意加载后，才在原 Chrome 的扩展管理页加载上述未打包目录。权限为 `activeTab`、`scripting`、`storage`，可选网站访问仅在点击允许时申请当前官方主机。Chrome 会保存已授予的主机访问，可在扩展设置撤销；跨至另一个官方主机时需另行允许。没有 Cookie、调试器、后台脚本、代理、外部接口或密码权限。加载或授权本身不等于允许购买。

当前浏览器工具无法访问 Chrome 内部扩展管理页，安全规则同时禁止通过其他接口绕过。你已经同意安装并只读验证，无需重复确认安装。加载必须由你本人在 Chrome 完成：打开扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选上述目录。先只安装，点击扩展图标打开 AppleBuy 控制页；后续由 Codex 核对安装结果，再请求所需的当前官方主机访问。安装权限不是新购买授权。

将官网正常购买页面打开后，点击扩展图标，打开控制页，选择唯一官网标签页，允许该主机访问，点“只读预检与读取当前条款”。确认商品、总额上限、一台、大连恒隆广场、首次提供的前三个日期依次每天末档、支付宝。需要的自提资料由本人预填，只保存在本次 Chrome 会话；官网已有资料可留空。**现有本机 DPAPI 资料尚未自动接入**，程序不读取账号密码，也不自动处理登录或验证。

10 月 3 日实际只读观察发现，“订单状态”在当前未登录的 Chrome 会跳至官网 `/shop/signIn/orders`，登录控件嵌在独立框架里。候选程序现在明确提示人工登录，不把这个页面当无货，也不会在这里发送购买动作。识别登录阻断不等于已经核对订单；当前没有重新获取任何账户订单。

购买前可分别点“只读观察当前公开配置”或“只校验公开选配”。前者没有点击，也不读取或创建购买任务；后者依次选择正常启用的规格选项、“不折抵换购”和“不加 AppleCare+”，重新核对规格与报价，停在加购前。它使用独立校验记录，没有加购、自提时段、订单或付款动作。所需控件未出现或禁用时只有限等待，不能强开。只读校验和选配校验均不等于允许购买。

原购买任务只有确实从未写入官网购物动作时才可点退役，历史保留。结果不明、曾经加购或提交的任务不能因此重新购买；本人确认改绑官网标签页后，该任务永久只做结果核对。网页在时段选择事件后改回较早档、换日期、换店、改价格或重绘控件时停止继续，保留已触碰状态，不能当成未发送而盲重试。

勾选“允许推进结账”，以及接受当前条款、已经核对没有同款待付款订单、不添加额外商品、只创建这张未付款订单的确认，才可一键推进至提交与查单。若不提前确认，程序只推进到复核页，再由本人确认。提前授权绑定原始页面、购买条件和唯一任务，20 分钟过期，不能换商品后复用。

暂停、停止、网页更新、超时或关闭控制页后保留已发送动作。再次打开不会清除记录、再加购或重发最终下单。另一控制页不能同时执行。遇到结果不明，先核对官网订单，不要删扩展数据重新启动；当前候选没有自动删除或重置购买记录的入口，也没有第二次购买入口。

**真实联调还欠什么**：官网购物袋与订单字段的完整识别、取货资料标签、日期/时间摘要及独立未付款详情路线、真实时段拒绝信号和更新后的列表。没有观察过的错误提示不会被编造为“时段拒绝”；程序会停止核实。历史 Pro 订单证明正常官网路径，但不证明这份扩展能独立跑通，且官网说明取货日期需付款后确定。当前严格摘要检查可能因此在真实复核/查单时停止，需要按实际证据完成适配。未付款核实也不意味着已付款或锁住时段。
