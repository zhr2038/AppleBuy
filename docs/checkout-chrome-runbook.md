## 遇到停止状态

- `AUTH`：登录／验证后核对原任务；密码、验证码和身份证件不用发给模型。
- `current-host-permission-missing`：仅处理显示的实际新官网主机权限，再只读核对。
- `existing-task-binding-differs`：商品或标签页与旧任务不一致，保留记录；改绑只读不恢复购买权限。
- `NEEDS_VERIFICATION` 且有待确认动作：不再次加购／提交；先核对已经发送的动作。
- `NOT_RELEASED` 或继续禁用：保留公开选择，不能把禁用改成可买。

查询失败不等于无货，超时不等于明确拒绝。暂停后不发新购买动作，已经发送的可能继续完成，短暂只读查单仍可能继续；再次打开保留原记录。当前真实官网拒绝信号、最新列表、时段保留、Duo后续契约、插件完整实跑和官网速度均未验证；普通模拟成功不保证首发抢到。
