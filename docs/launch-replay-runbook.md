# 开售页面回放说明

这是 C-007 的离线候选：只回放本机合成页面，未接入真实结账，尚待 Claude 实际复审。

在 `E:\Apple Store` 运行：

```powershell
node src/cli.ts app --task-dir .local/launch-browser --plan examples/plan.launch.fake.json
```

用电脑 Chrome 打开终端打印的地址，再打开同一地址的 `/launch`。页面默认展示当前进度、样本选择和候选；观察 JSON 与异常验证折叠在下面。

1. 依次观察“尚未开售”“疑似维护文案”“尚未加载完整”“入口恢复”：区别页面状态，保留原任务和购买计划，旧引用失效。
2. 观察“日期与原生时段控件”：在完整合成样本中绑定最初至多三个允许日期，每天只建议实际列表的末档。
3. 观察“重排并更换控件”或“原生日期单选与时段选择”：从当前 DOM 重新读控件；旧页面引用不能使用。
4. 观察“末档被移除”：不会自动改选当天更早档。观察“选择第四个日期”：不能扩大已绑定范围。
5. 暂停后退出原服务，再以原目录重启：暂停、绑定日期、末档和历史均保留；恢复后需要新观察。
6. “日期缺少年份”“自提控件未选中”“商品不符”“要求登录”“要求确认条款”“限流”“访问限制”“无法识别的改版”会停止建议或交给本人处理。网络失败或没有维护文案的 503 不能当作无货或已确认维护。

“模拟提交结果不明”只设置虚构待核实证据，不发送订单。设置后，即使页面恢复、重启或换布局，也先核实，不能重发；本页没有清除这种证据的按钮。不要删历史或另建任务来重试同一真实购买意图。

命令行单独验收合成 AST：

```powershell
node src/cli.ts launch-replay --task-dir .local/launch-cli-check
```

首次执行输出 20 个场景、日期绑定、未知结果保留与外部网络调用数。再次使用已有待核实目录会拒绝继续，这是预期保护。CLI AST 不等于实际 Chrome DOM，也不等于 Apple 接受。

导入仅接受规定的脱敏语义字段，拒绝额外字段和个人资料。即使导入声称列表完整，来源仍未独立核验，不能产生可执行候选。真实页面列表的完整性、年份、产品/规格/数量/价格/直营店绑定必须有独立当前证据，不能由合成样本迁移。
