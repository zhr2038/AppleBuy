# 当前购买通道的限制

独立购买主机已按本次明确授权登记，并核验两种注册表视图和扩展来源绑定。购买通道已连接，程序已实际完成 Pro 配置、加购这一台和结账，目前官网要求本人登录，尚未生成新的未付款 Pro 订单。账户身份、旧结账停止和没有已有待付款同款订单，需要本人刚在官网订单列表核对；程序不会把未登录空购物袋当作账户证明。本轮仅推进订单复核，最终提交另需当前条款确认。

新尝试最多三代，同时还有保守的历史大小检查；历史较大时，实际可继续次数可能少于三代。达到任一限制会停止，不删除历史或放宽条件。

同一窗口中的新任务过期后，接口支持明确另建新尝试，但当前窗口的按钮可能仍禁用。需要先暂停、正常关闭本程序窗口，再打开并只读核对；仍需本人核对当前账户、旧官网结账停止和订单列表。不要删除或手动改写任务文件。

Python broker 使用本机 PATH 中的 Python；host 安装器固定当时的 Python 可执行文件。实际部署前要核对两者，不能用未经确认的解释器或绕过系统、浏览器权限。

关闭或刷新连接页时，已发动作可能仍在执行，也可能遗留程序自己的只读购物袋页。保持连接页打开，暂停使用桌面程序；未知结果不代表失败，不能重发订单。

这些限制不改变目标：唯一一台 Pro256GB黑色、大连恒隆直营店自提、上限¥9,999、首次最多三个日期依次末档、支付宝、无折抵/AppleCare/配件/分期，停止在未付款订单。当前条款确认和认证仍在实际步骤处理，Duo实购在Pro完成后继续。

执行器内部的明确暂停/关闭已修复为等待初始化及只读请求结束，再关闭本程序的标签页并释放锁。尚未覆盖父进程提前强制结束和 worker 未就绪时的停止；运输结果不明时仍须保持清理未确认，不能再次启动或声称成功。必须核实所属进程结束，旧记录保留。新的按钮延迟等待使用共享约3秒预算，较慢页面仍可能正常停止，需要明确继续；不能把停止称为无货。当前暂停的官网验证页可能在私有操作进程闲置超时后正常关闭，任务记录和购物袋不会因此当作空袋或失败。
